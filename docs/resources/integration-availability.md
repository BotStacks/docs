Website deployment is the focus of these guides. Start with [CMS Deployment](/products/cms-deployment) for Wix, Webflow, Squarespace, and Bubble. GoDaddy Airo remains a separate compatibility evaluation.

## Older channel and business-system guides
Older documentation described Slack, Discord, WhatsApp, CRM, and Crisp integrations. Their current self-service availability and installation steps have not been validated for this documentation release. The obsolete setup instructions have been retired rather than presented as working procedures.

Do not create apps, enable privileged permissions, or paste provider tokens based on an old guide. Check the integrations available in your current workspace and request a verified setup path from support.

## If you have an existing connection
Do not remove a working connection solely because its guide changed. Record its purpose and owner, protect its credentials, and confirm the supported update or migration procedure before making changes. Test with a non-production destination where possible.

## Before relying on an integration
Confirm the target account, supported action, required permissions, error behavior, removal method, and a successful end-to-end test. A connection screen or repository alone is not evidence that messages, notifications, or business actions are delivered.

[Contact support](/resources/contact-support) with the integration name and intended use.
