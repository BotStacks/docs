## Start with public product help and clear account-access boundaries
Choose a small set of public pages that answer repeated visitor questions. Use the [knowledge guide](/website-guides/knowledge) to prepare them before importing.

## Decide where help belongs
Pick a page where visitors often need clarification. Write three questions that page should answer. Avoid adding chat to sensitive or transactional screens until you have verified its behavior there.

## Install only from workspace instructions
Confirm your Bubble plan and permissions allow the required installation method. Use the deployment instructions available in BotStacks; this checklist does not establish native integration support. If your workspace does not provide a suitable method, contact support before proceeding.

## Verify on your published site
Test logged-out and logged-in experiences separately. A website embed does not grant access to Bubble user data; verify any data integration separately.

Ask your three questions in the live widget and compare the answers with your approved source pages. Check that missing information results in a clear contact route rather than a guessed answer.

## Before launch
Complete the [test and launch checklist](/website-guides/test-and-launch). Recheck installation after changing themes, page templates, or publishing settings.

## Installation steps
Use the current [Bubble installation guide](/common-tasks/integrations/bubble-integration) for platform-specific setup, verification, and removal.
