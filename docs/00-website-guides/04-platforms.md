## Before installing
Use the embed or deployment instructions generated by your BotStacks workspace. Confirm your website plan permits the required code and that you have publishing permission. Do not copy a sample assistant ID or invent an installation snippet.

If no suitable deployment option is available, contact [support](mailto:support@botstacks.ai) with your platform and the step that is blocked. Never send passwords or private API keys.
